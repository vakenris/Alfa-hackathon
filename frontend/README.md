# Альфа Бизнес

React + TypeScript + Vite. Локальный интерфейс по предоставленным макетам.

Запуск: `npm install`, затем `npm run dev`. Сборка: `npm run build`.

## Архитектура

- `src/components`: Sidebar, NewsCard, Icon, общие элементы UI и модальное окно.
- `src/pages`: главная, подробная новость, анализ и личный кабинет.
- `src/data`: типизированные демонстрационные данные, общие для карточек и страниц.
- `src/hooks`: сохранение профиля и выбранной компании в localStorage.
- `src/App.tsx`: каркас и hash-маршрутизация, не требующая rewrite на хостинге.
- `src/index.css`: токены и базовые стили; `src/App.css`: адаптивные компоненты.

В навигации три раздела: Главная, Анализ, Личный кабинет. Новость открывается из карточки. Выбор компании общий для разделов. Профиль редактируется в модальном окне и сохраняется в браузере.

Данные, оценки, сценарии и рекомендации демонстрационные. Backend, авторизация и ИИ не подключены. Ссылки источников ведут на главные страницы изданий. Фотографии извлечены из пользовательских макетов. Manrope загружается из Google Fonts, при отсутствии сети используется Arial.

## Назначение разделов

- Главная: лента новостей с фильтрами по темам, выбор компании и переход к подробной новости.
- Анализ: последствия событий для компании, рекомендации, сценарий финансирования и план действий. Повторной ленты новостей нет.
- Личный кабинет: профиль и доступные компании.

План действий сохраняется отдельно для каждой компании в localStorage. Оценки и сценарии демонстрационные, финансовые данные компаний не подключены.

## Разбор события и сводный анализ

Страница новости содержит описание одного события и механизм его влияния. Общие рекомендации и сценарии на ней не дублируются.

Реестр рисков, сценарий финансирования и общий план действий находятся только в разделе «Анализ». Переход из новости передаёт `source` в hash-маршруте и подсвечивает связанные риски и задачи, сохраняя сводку по всем событиям. Отметки плана по-прежнему сохраняются отдельно для каждой компании.
