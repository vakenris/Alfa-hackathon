# Банковские PDF: импорт и поиск

Команды выполняются из корня проекта. Python-зависимости перечислены в
`requirements.txt`. Для сканов нужен отдельно установленный Tesseract 5.x
с языками `rus` и `eng`.

## Файлы

- `data/raw/bank_analytics/`: исходные PDF, локально.
- `data/processed/bank_analytics/`: результат извлечения, локально.
- `data/bank_analytics_manifest.json`: названия, даты и SHA-256 исходных PDF, в Git.

Пример PowerShell для стандартного пути установки Tesseract:

```powershell
.\.venv\Scripts\python.exe -m backend.app.ingestion.pdf_reader --input .\data\raw\bank_analytics --output .\data\processed\bank_analytics --tesseract "C:\Program Files\Tesseract-OCR\tesseract.exe" --tessdata-dir "C:\Program Files\Tesseract-OCR\tessdata"
$env:DATABASE_URL = "sqlite+aiosqlite:///./alfa_real_data.db"
.\.venv\Scripts\python.exe -m backend.app.cli ingest-analytics --dry-run
.\.venv\Scripts\python.exe -m backend.app.cli ingest-analytics
.\.venv\Scripts\python.exe -m backend.app.cli search-analytics --query "ключевая ставка" --as-of 2026-09-15 --include-unreviewed
```

Повторный импорт пропускает уже загруженные документы. Изменение текста или
метаданных загруженного PDF вызывает ошибку. Текст страниц сохраняется без
нормализации; нормализация применяется только во время поиска.

## Границы поиска

По умолчанию поиск и адаптер агента используют только вручную сверенные
страницы. `--include-unreviewed` включает сырой OCR только для предпросмотра
оператором. Такой результат не допускается в адаптер агента.

Поиск лексический: регистр, `ё/е` и распространённые русские окончания.
Оценка `score` не является вероятностью или оценкой качества LLM.
Рассматриваются не более 300 наиболее новых датированных страниц;
для ранжирования используются первые 50 000 символов каждой страницы.
В результат попадает лучшая страница каждого найденного документа.
Это ограниченная выборка, а не векторный поиск по произвольному корпусу.

Документы без установленной даты публикации исключены из поиска по дате.
Исторические документы включаются только с `--include-historical`.
Период обзора золота `2026-08` не подставляется вместо даты публикации.

## Ручная сверка

`show-analytics --document DOCUMENT_SHA256 --page 1` выводит метаданные и
сырой текст выбранной страницы. Оператор сверяет её с исходным PDF,
включая цифры и отрицания. После сверки он может выполнить:

```text
review-analytics --document DOCUMENT_SHA256 --extraction-hash EXTRACTION_SHA256 --pages 1
```

Это подкоманда `python -m backend.app.cli`. Оба хеша берутся из вывода
`show-analytics`. Команда фиксирует заявление оператора о ручной сверке,
проверяет целостность и сохраняет время сверки, версию текста и хеш страницы.
Она не выполняет визуальное сравнение автоматически и не проверяет
истинность экономических выводов. При найденной ошибке статус оставляют
`unverified`; исправление загруженной версии требует отдельной процедуры.
Графики и таблицы с потерянными запятыми или смешанными подписями не допускают
к агенту. Допуск страницы 1 не означает допуск остальных страниц документа.
Старый общий флаг `manual_review` не заменяет новую постраничную сверку.
`review_required_documents` в отчёте импорта описывает исходный OCR;
актуальные допуски страниц видны через `show-analytics`.

## Передача Backend1 и ML

После объединения с ML-веткой адаптер доступен так:

```python
from backend.app.ingestion.analytics_source import BankPdfAnalyticsSource

source_factory = lambda: BankPdfAnalyticsSource(async_session_factory)
```

Эту фабрику владелец запуска передаёт в `RuntimeAgentEngine`.
Адаптер не регистрируется в `main.py` или worker автоматически.
Класс `AnalyticsDocument` импортируется только при вызове адаптера.

Агент получает исходный текст страницы, ID документа, номер страницы,
SHA-256 PDF и статус сверки. URL отсутствует, если не предоставлена
подтверждённая ссылка. Непроверенная страница не передаётся агенту.

Время публикации PDF неизвестно: хранится дата. Для агента применяется
консервативная граница доступности — конец этого дня UTC. Документ того же
дня обычно станет доступен агенту со следующего дня. Это граница для
фильтрации, а не установленное время выпуска документа.

Эмбеддинги, внешний провайдер и автоматическая регистрация LLM этим
модулем не настраиваются. Тесты запускаются командой `python -m pytest -q`.
